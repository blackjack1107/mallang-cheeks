# 말랑볼 (Mallang Cheeks)

사진 속 볼을 잡아당겼다 놓으면 말랑하게 튕겨 돌아오는 브라우저 장난감입니다.
설치·가입·서버 없이 정적 파일만으로 동작하고, 사진은 브라우저 밖으로 나가지 않습니다.

## 기능

- **사진 불러오기** — 파일 선택, 끌어다 놓기, 붙여넣기 (JPG / PNG / WebP / GIF 첫 장면). 긴 변 1024px로 줄여서 사용
- **샘플** — 코드로 직접 그린 물범 그림으로 바로 시작
- **볼 맞추기** — 점선 원 두 개를 볼 위로 옮기고, 테두리를 끌거나 슬라이더로 크기 조절
- **칠하기** — 브러시/지우개로 말랑할 영역을 직접 지정, 사진 전체를 말랑하게 만들기
- **말랑말랑** — 잡고 당기면 늘어나고, 놓으면 출렁이며 복귀. 멀티터치로 양쪽 동시에 당기기
- **자동으로 당기기** — 손대지 않아도 세 번 당겨 줌
- **녹화** — 최대 15초, MP4(지원하지 않는 브라우저는 WebM). 같은 녹화로 GIF 만들기, 공유
- **PNG 저장**, 배경색(프리셋 + 직접 고르기), 화면 비율(9:16 / 1:1 / 4:5)
- **말랑함 설정** — 말랑함 · 출렁임 · 잡히는 범위 · 늘어나는 길이
- 되돌리기, 효과음 켜고 끄기, 한국어 / English / 日本語

## 실행

`index.html`을 브라우저로 열면 됩니다. 로컬 서버로 띄우려면:

```bash
python3 -m http.server 5173
```

그다음 <http://localhost:5173> 을 엽니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 화면 |
| `js/app.js` | WebGL 메시 렌더링, 스프링 물리, 포인터 입력, 녹화 |
| `js/gif.js` | 의존성 없는 GIF 인코더 (미디언 컷 팔레트 + LZW) |
| `js/sample.js` | 샘플 그림 (Canvas 2D로 그림) |
| `js/i18n.js` | 화면 문구 |

동작 원리: 사진 위에 격자 메시를 깔고, 원/칠한 영역에서 꼭짓점별 "말랑함" 가중치를 만듭니다.
잡은 지점 주변 꼭짓점은 당긴 방향으로 끌려가고, 놓으면 감쇠 스프링과 이웃 결합으로 출렁이다 제자리로 돌아옵니다.

## 출처

볼을 늘리는 웹 장난감이라는 아이디어는 saba(Saba no Games)의 「もちほっぺ・メーカー」에서 시작됐습니다.
이 프로젝트는 그 아이디어에서 영감을 받은 비공식 프로젝트로, 이름·디자인·샘플 그림·코드는 모두 새로 만들었고 원작의 자산은 쓰지 않았습니다.
